# Data

Declare your dataset here before you collect any model output.

| | |
|---|---|
| **Source** | Who made it, with a link |
| **Retrieved on** | The date you downloaded or accessed it |
| **Where it is** | A file in this folder, or a link if the data is too large or may not be redistributed |
| **SHA-256** | For a file in this folder. It shows later that the file has not changed |
| **Licence** | What the source allows you to do with the data |
| **Columns** | What each column means. Include `item_id`, which your run log uses |

[Declaring your data](https://github.com/Princeton-AI-Exploration-Lab/kits-catalog/blob/main/GITHUB.md#declaring-your-data)
explains each field and how to compute the checksum.
