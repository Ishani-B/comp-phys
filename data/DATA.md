|---|---|
| **Source** | Synthetic. Generated by me with [`scripts/generate_items.py`](../scripts/generate_items.py) in this repo. There is no outside dataset. Each item is a table of 6 (seconds, meters) pairs produced by one formula, plus one new time to ask about. |
| **Retrieved on** | Generated 18 November 2026. The script has no randomness, so running it again gives the identical file. |
| **Where it is** | [`freefall_starter.csv`](freefall_starter.csv), 30 items (Starter design) |
| **SHA-256** | `2544157be9c08f0b640c79ca185863ff5ce51296261bede5af9eaf9164da474e` |
| **Licence** | My own work, no third-party content. Free to copy and redistribute. |
| **Columns** | See below |

| Column | Meaning |
|---|---|
| `item_id` | `FF-<R/N/F>-<01..10>`: free-fall, law distance (real / near / far), item number. The run log uses this. |
| `domain` | Always `free_fall` in the Starter |
| `law_distance` | `real`, `near` (changed constant) or `far` (changed exponent or form) |
| `law_variant` | `real`, `near_smaller_constant`, `near_larger_constant`, `far_changed_exponent` or `far_changed_form` |
| `formula` | The law that generated the table, e.g. `d = 2.5 * t^2` |
| `coefficient`, `exponent` | The same law as numbers: d = coefficient × t^exponent |
| `table` | The 6 points shown to the model, t = 1 to 6 seconds |
| `test_t` | The new time the model is asked about (7 to 16; every condition uses each once) |
| `cf_answer` | Correct answer under the law in the data |
| `real_answer` | What real free-fall (d = 4.9 t²) gives at `test_t`. For real-law items it equals `cf_answer` |
| `prompt_id` | The prompt template used, from [`prompts/prompts.md`](../prompts/prompts.md) |
| `prompt` | The full text sent to the model |

## How the items were chosen

- **Real (10):** d = 4.9 t², asked at T = 7, 8, …, 16.
- **Near (10):** d = k t² with k = 1.2, 1.5, 2, 2.5, 3 (smaller than 4.9) or 7, 8, 9, 10, 12 (larger). Every constant is at most 0.65× or at least 1.4× the real one, so the gap between the two answers is never tiny.
- **Far (10):** d = c t³ with c = 0.5, 1, 1.5, 2, 3, or d = c t with c = 8, 10, 12, 15, 20.
- All three conditions ask about the same 10 test times, so the law is the only thing that changes. Within near and far, the two sub-variants are split across test times so their average T is nearly equal (57 vs 58 summed).
- The 5 sample items in the data plan are included exactly: `FF-R-02`, `FF-N-02`, `FF-N-04`, `FF-F-02`, `FF-F-03`.

## Checking the answer key

[`scripts/check_items.py`](../scripts/check_items.py) recomputes every table value and both answers from the stated formula without using the generator's code, confirms the 5 sample items match the plan, and confirms no prompt contains a physics term (gravity, acceleration, physics, Earth). Run it with `python3 scripts/check_items.py`.

## Pilot: harder evidence

Two more files, generated 18 November 2026 by [`scripts/generate_pilot.py`](../scripts/generate_pilot.py) (fixed seed 20261118, so rerunning gives identical files) and checked by [`scripts/check_pilot.py`](../scripts/check_pilot.py). Both use the Starter's 30 laws and test times; only the points shown differ. Design: "Pilot: harder evidence" in [`PLAN.md`](../PLAN.md).

| File | Points shown | SHA-256 |
|---|---|---|
| [`freefall_pilot_noisy.csv`](freefall_pilot_noisy.csv) | t = 1 to 6, each value × a random factor in [0.9, 1.1], rounded to one decimal | `c4a2788eb5343c8bf82456f846f8c909d9e80bf1f240bce6f65892ded44c5c29` |
| [`freefall_pilot_sparse.csv`](freefall_pilot_sparse.csv) | t = 1 to 3, exact | `e0b66b078ccc11e6752f0cff81c29a172e162201913092025f908d7b7ee00dc6` |

Columns are the Starter's, plus:

| Column | Meaning |
|---|---|
| `evidence_level` | `noisy` or `sparse` |
| `t2_fit_answer` | What d = k·t², with k fitted by least squares to the points shown, gives at `test_t`. Descriptive only. |
| `quad_fit_answer` | What a least-squares fit of a·t² + b·t + c gives at `test_t`. Descriptive only. |

Item IDs are `FFNZ-…` (noisy) and `FFSP-…` (sparse). `cf_answer` still comes from the noise-free law.

## Standard run: Hooke's law and Kepler's third law

| File | Items | SHA-256 |
|---|---|---|
| [`hooke_standard.csv`](hooke_standard.csv) | 30: weight (g) → spring stretch (cm) | `fffb7a87463f82ccdd4e5ee6de5e02a82fa3fa98a4f1adda6ae1a126f35507cd` |

Columns are the Starter's, with these differences:

| Column | Meaning |
|---|---|
| `formula` | y = c · (x/scale)^p, scale 100 g (Hooke) or 10 thousand km (Kepler) |
| `test_x` | The value asked about (700–1600 g, or 70–160 thousand km) |
| `test_t` | The same point in scaled units (7–16), the role T plays in the Starter |
| `real_answer` | The real law's form with its constant fitted (least squares) to the 6 points shown: a straight line through zero for Hooke, distance^1.5 for Kepler. There is no single real-world constant for either law. |

Item IDs are `HK-…` and `KP-…`. Shown values are rounded to 2 decimals; `cf_answer` comes from the exact law.
